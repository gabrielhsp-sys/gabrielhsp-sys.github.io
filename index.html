Como eu cheguei aqui

Depois de quebrar e consertar o PC de casa algumas vezes, ficou claro que eu gostava mais de abrir a máquina do que de usar ela. Isso virou curso: Ciência da Computação na UNIFAL-MG.

A mesma pergunta — o que tem por baixo disso? — me puxou para os dois extremos. Para baixo, C e C++, gerenciando memória na mão e entendendo o que o computador realmente faz. Para cima, Java com testes, padrões de projeto e CI/CD, além de web e PWA.

No meio dos dois tem um servidor Linux embaixo da minha mesa rodando meus próprios serviços em Docker — senhas, fotos, mídia e Git. O acesso é por Tailscale, sem uma única porta aberta para a internet. É ali que eu quebro as coisas primeiro, antes de quebrar em outro lugar.

Trabalho de um jeito meio cético: antes de adotar uma ferramenta porque está na moda, quero ver que ela resolve o meu problema. Prefiro entender o porquê a decorar o como.

academic-system — detalhes.md

projeto · java · poo

Academic System

O que é

Sistema de gestão acadêmica em Java que administra turmas e avaliações, com dois papéis de acesso: administrador e professor. Roda em linha de comando e em interface gráfica JavaFX, reaproveitando exatamente a mesma lógica de negócio.

O escopo funcional é enxuto de propósito. O objetivo não era ter muitas telas — era ter engenharia de verdade em volta de um domínio pequeno.

Arquitetura

Camadas com responsabilidade separada: View → Controller → Service → Repository → Model. A interface nunca fala direto com o domínio; passa pelo controller, que autoriza e delega. Segurança e validação ficam transversais. A prova de que funcionou: a GUI inteira entrou sem alterar uma linha de regra de negócio.

Decisões que valem citar

RBAC com uma matriz de permissões como fonte única de verdade — o menu esconde, a autorização bloqueia — mais trilha de auditoria dedicada.

Repository + Strategy para persistência intercambiável em TXT, XML e JSON sem o domínio saber o formato. Trocar o formato não toca no domínio. Também usei Singleton, hierarquia polimórfica de avaliações e Bean Validation.

13 classes de teste em JUnit 5 e Mockito, incluindo testes de interação com verify(), e cobertura medida com JaCoCo.

4 workflows de CI/CD: build e testes, validação de pull request, imagem Docker publicada no GHCR e release por tag. Docker multi-stage e branch protection ligados.

homelab — detalhes.md

infraestrutura · linux

Homelab Self-Hosted

O que é

Um servidor Debian montado em casa para hospedar meus próprios serviços em vez de depender da nuvem dos outros: gerenciador de senhas, backup de fotos, sincronização de arquivos, streaming de mídia, Git próprio e monitoramento.

O problema interessante

Meu provedor usa CGNAT — não tenho IP público, então redirecionar porta simplesmente não é uma opção. A saída foi montar uma rede privada com Tailscale: acesso de qualquer lugar, criptografado, sem abrir uma única porta e sem expor nada à internet pública. A superfície de ataque é praticamente zero por construção, não por configuração caprichada.

Como está montado

Cada serviço isolado no seu contêiner Docker, tudo gerenciado por painel via navegador. É Linux, redes e administração de sistemas na prática — com a vantagem de que, quando eu derrubo alguma coisa, o usuário prejudicado sou eu.

disciplina · programação lógica

Ordenação em Prolog

O que é

Dois predicados que ordenam listas de listas: um pelo comprimento das sublistas e outro pela frequência desses comprimentos.

A parte difícil

Implementação recursiva com a estratégia decorate–sort–undecorate, mantendo a estabilidade da ordenação. Isso depende de uma sutileza de um caractere: usar =< em vez de < preserva a ordem original entre elementos iguais. Verificado no SWI-Prolog contra os resultados esperados.

Foi o exercício que mais mexeu com a minha cabeça — descrever o que é uma lista ordenada, em vez de dizer ao computador como ordenar, é um jeito completamente diferente de pensar.
