Uma reinstalação deveria terminar com uma máquina melhor documentada, não com a sensação de que meia dúzia de comandos importantes sumiram da memória.

Este guia organiza o pós-instalação do Fedora 44 como uma sequência copiável, verificável e reversível. Ele cobre atualização do sistema, RPM Fusion, codecs, drivers, Secure Boot, snapshots e a base para jogos.

## Princípio

Cada bloco precisa dizer o que muda e como confirmar que funcionou. Quando a alteração pode afetar o boot ou o sistema de pacotes, a saída também precisa incluir recuperação ou rollback.

O guia está em `CODEX`: não é um projeto encerrado, mas uma referência que deve acompanhar novas versões do Fedora.
