Fedora pós-instalação

Guia copia e cola em português para o Fedora 44 Workstation.

  1. Atualizar o sistema
  2. Plugins do dnf5
  3. Codecs
  4. Flatpak
  5. Snapshots
bash · Fedora 44 Workstation (dnf5)
sudo dnf upgrade --refresh -y
sudo dnf install -y dnf5-plugins
sudo dnf swap -y ffmpeg-free ffmpeg --allowerasing
flatpak remote-add --if-not-exists flathub \
https://flathub.org/repo/flathub.flatpakrepo
sudo snapper -c root create-config /

Em menos de 15 minutos, com como desfazer.

O guia termina com uma seção de como desfazer os ajustes de kernel, memória e disco.
